## 第 8 页：电压记录的重新计算

表中负载为标称 2.2 kΩ。使用原始显示电压计算，不从已四舍五入的电流列反算：

```text
I_estimated (mA) = V_measured (V) / 2200 (Ω) × 1000
relative_deviation (%) = (I_estimated − I_set) / I_set × 100
```

| 设定电流 / mA | 记录电压 / V | 计算电流 / mA | 相对偏差 / % |
| ---: | ---: | ---: | ---: |
| 1 | 2.201 | 1.000455 | +0.045455 |
| 2 | 4.401 | 2.000455 | +0.022727 |
| 3 | 6.601 | 3.000455 | +0.015152 |
| 4 | 8.798 | 3.999091 | −0.022727 |
| 5 | 11.003 | 5.001364 | +0.027273 |
| 6 | 13.200 | 6.000000 | +0.000000 |
| 7 | 15.405 | 7.002273 | +0.032468 |
| 8 | 17.602 | 8.000909 | +0.011364 |
| 9 | 19.797 | 8.998636 | −0.015152 |
| 10 | 22.002 | 10.000909 | +0.009091 |

该表最大绝对相对偏差为 **0.045455%**，发生于 1 mA 设定点。原 PPT 的“最大约 ±0.10%”属于较宽的概括，本页保留逐项计算结果。

以上只是对已有数字的重算，不增加测量精度。CSV 另外保留 PPT 展示的电流和误差列，避免丢失原来的四舍五入信息。

## 已有材料可以说明什么

- 已有系统连线、触屏和示波器照片，支持“已完成可操作原型联调”的课程记录。
- 波形照片可用于观察方波和指数衰减形态，仪器有约 20 Hz 的频率显示。
- 两组电流表可以复核数值计算，支持讨论逐点标定与插值。
- 当前源码可定位 DAC 表、ADC 均值采样、分压补偿和串口命令。

## 尚不能从现有材料推导的结论

- 全量程、全负载、温漂和长期稳定性下的输出精度。
- 50 kΩ 测量上限及全量程 <0.2% 的阻抗精度。源码中的 50000 Ω 是结果限幅。
- 实际负载端负向电流、零净电荷、医疗电气标准合规或临床效果。
- 页面绘图等同于端口采样波形，或历史照片就是当前固件的复测。
- 通信失效、故障状态和软件停止的最坏响应时间。

现有资料未完整包含负载实测值与容差、供电记录、探头位置与倍率、仪器量程与校准状态、重复测量次数、环境温度，以及烧录固件的版本标识。

## 当前代码与答辩描述的差异

| 项目 | 答辩或旧说明 | 当前源码依据 |
| --- | --- | --- |
| 输出中断 | 1 kHz、1 ms | TIM1：Prescaler 71、Period 49；72 MHz 时钟下为 20 kHz、50 μs |
| 串口 | 旧 README 为 USART1/2、115200 bps | USART2 与 USART3，均为 9600 bps |
| DAC 通道 | 答辩第 16 页写 SPI 写入 | 片内 DAC 寄存器写入 |
| 指数波上升 | 旧 README 为 4 ms | 回调内为 2.0 ms 或 0.5 ms |
| 无线方式 | 答辩总结有“蓝牙”字样 | Lua 实现 Wi-Fi SoftAP + HTTP |
| 波形预览 | 部分表述为实时波形 | 按参数绘制，非 ADC 实时波形 |
| 故障处理 | 答辩架构图含故障锁存 | 当前代码未形成完整自动故障锁存状态机 |
| 保护与精度 | 旧说明声称开路关断、动态换挡及全范围精度 | 不能从当前实现及记录确认这些声明 |

## 复核方法

在仓库根目录运行：

```sh
python3 tools/calibration_summary.py
```

脚本仅重新计算两组 CSV，使用 Python 3 标准库。它不验证硬件、不生成新的实测数据，也不将标定记录升级为认证报告。
